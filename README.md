# dsh-identity-gate

给 [DSH（DeepSeek Harness）](https://github.com/deepseek-ai) 加一道**四重身份门禁**：打开界面先按顺序验证身份名称、身份编号、权限等级、密码，四项全对才解锁。

这不是安全产品，是一把「别人别随手动我电脑」的软锁。它挡的是顺手操作的人，不挡懂技术的人——这一点请先看清再装。

## 功能

- **四项验证**：身份名称 → 身份编号 → 权限等级 → 密码，错一项都不开
- **锁定时机可调**：启动 DSH 时锁 / 每次页面加载都锁 / 仅手动锁
- **手动锁定**：侧边栏底部的锁按钮，点一下、确认、即锁
- **密保恢复**：忘了任何一项，答对密保问题后自动预填当前身份信息，改完保存即解锁
- **后台照跑**：只锁界面，agent 回合、定时任务、插件 prompt 都不受影响

## 安装

在 DSH 的**插件市场**搜索 `dsh-identity-gate`，一键安装。

或者命令行：

```sh
dsh plugin add dsh-identity-gate
```

安装后刷新页面。首次使用请先到 **设置 → 锁屏** 填好身份信息与密码。

## 使用

1. **设置 → 锁屏**：填身份名称 / 编号 / 等级并保存；设密码；设密保问题
2. 选锁定时机（默认：启动 DSH 时锁）
3. 离开时点侧边栏的 🔒

身份信息未填写时，解锁只要求密码（向后兼容）；填好后自动切换为四项验证。

## 和启动动画插件共存

如果你装了 `dsh-startup-screen` 这类在页面加载前就渲染动画的插件，本插件会自动在锁定期间拦下它、解锁后再从头播放。两者不需要配置。

## 安全边界

- 密码以加盐 SHA-256 存储，明文不落盘；身份名称 / 编号 / 等级存于本机 localStorage，它们是识别信息，不是秘密
- 禁用或卸载插件，锁就没了
- 清掉站点数据，密码与设置一并重置
- 直接访问本地接口、读会话文件、开 devtools，都绕得过去

真正的「离座防人」应该用系统的 Win+L。这把锁的定位是：让摸到你电脑的人多一道心理门槛。

## 兼容性

- DSH Desktop / `dsh web`，要求 `dsh >= 0.2.0`
- 无外部依赖，不需要构建

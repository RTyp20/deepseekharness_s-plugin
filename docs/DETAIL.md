# dsh-lock

启动锁：给 DSH 界面加一道密码门，防止别人趁你不在随手翻动。

## 做什么

- **四项验证** —— 解锁要按顺序填：身份名称、身份编号、权限等级、密码；四项全对才开
- **启动时锁定** —— 打开 DSH 先看到一扇锁着的门
- **手动锁定** —— 侧边栏底部的锁按钮，点一下确认即锁
- **锁定时机可选** —— 启动时 / 每次页面加载 / 仅手动
- **密保问题** —— 忘了任何一项都能恢复：答题通过后预填当前身份信息，改完保存即解锁
- **后台照跑** —— 它只锁界面，agent 回合、定时任务、插件 prompt 都不受影响

## 怎么用

1. 设置 → 锁屏：填身份名称 / 编号 / 等级，保存；再设密码与密保问题
2. 选锁定时机（默认：启动 DSH 时锁）
3. 离开时点侧边栏的锁按钮

身份信息未填写时，解锁只要求密码（向后兼容）；填好后自动切换为四项验证。

## 限制（重要）

这是一个**软锁**，不是安全产品。它挡的是顺手操作的人，不是懂技术的人：

- 禁用或卸载本插件，锁就没了
- 清掉站点数据（localStorage），密码与设置一并重置
- 直接访问本地接口、读会话文件、开 devtools，都绕得过去

真正的“离座防人”应该用系统的 Win+L。这把锁的定位是：让摸到你电脑的人多一道心理门槛，而不是保护数据机密性。

## 存储

密码与密保答案以加盐 SHA-256 存于本机浏览器的 localStorage，明文不落盘。
